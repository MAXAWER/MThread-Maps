# Прогулка — ИИ-помощник по прогулкам в Астане

Прототип для хакатона Build with AI (задача НИЦ Smart City). Полное ТЗ — [docs/TZ.md](docs/TZ.md).

- **Android** (`android/`): Kotlin, Jetpack Compose (Material 3, размытие Haze), MVVM + StateFlow, Room, WorkManager, OkHttp (SSE), Fused Location, Activity Recognition. Карта — растровые тайлы 2ГИС на собственном Compose-canvas (жесты, инерция, маршруты, остановки), свой навигатор с голосом.
- **Сервер** (`server/`): Python 3.12, FastAPI, httpx, SDK `anthropic`, pydantic. Деплой — Firebase Cloud Functions (основной) или Cloud Run.
- **Модели**: Claude Sonnet 5.5 — агент поиска (сам ищет места, смотрит подробности, проверяет варианты поездки и выбирает лучший); Jev (TypeSafe System One) + Claude Haiku 5.5 — быстрый запасной путь, портрет, тексты.

### Что нового в 0.4.0

- **ИИ видит меню и цены**: агент ищет в интернете (Anthropic web search/fetch) меню заведений, цены блюд и товаров и показывает их в карточке с источником («Горячий шоколад — 1600 ₸ · glovoapp.com»).
- **Многоуровневые запросы и маршрут по нескольким точкам**: «сдать телефон в ремонт, пока чинят — какао, потом парк» — агент подбирает место на каждый шаг, сравнивает порядок (`check_trip`) и строит маршрут через все точки с временем прибытия и ухода.
- **Адреса и сохранённые места**: `find_address` для любого адреса; быстрые маршруты («Дом», «Брат») с иконками в профиле и кнопками на карте; ИИ предлагает запомнить место, сохраняется только с согласия. Адрес в строке поиска ищется мгновенно, без ИИ.
- **Навигация на транспорте**: к какой остановке идти, номер и цвет автобуса, сколько остановок до выхода, ближайший рейс или интервал, все шаги и остановки списком; голос — о посадке и выходе.
- **Карта**: камера следует, пока вы не тронете карту («Следовать» возвращает); поворот двумя пальцами и компас; конус направления взгляда; кнопка «моё место» в трёх режимах; тайлы кэшируются на диск, Астана и окрестности предзагружаются.
- **Подсказки под человека**: время суток, интересы, недавние запросы.
- **Стек**: Compose BOM 2026.09, Material 3 1.5 Expressive (MotionScheme.expressive, LoadingIndicator), AGP 9.4, Kotlin 2.4, compileSdk 37.

### Что нового в 0.3.0

- **Агент Sonnet 5.5**: по запросу «проложи маршрут в университет» он ищет несколько вариантов, проверяет, что это действительно вуз, сравнивает дорогу (автобус, пешком, авто) и сразу открывает маршрут. Ход работы виден вживую: капсула над картой, мысли выезжают из-под строки.
- **Маршруты**: до 6 вариантов общественного транспорта (номера, цвета, остановки на карте, отправление «через N мин» или интервал), альтернативы для пешком/вело/авто; любой вариант можно выбрать. Позиции автобусов в реальном времени в Астане публично недоступны — показываем остановки и расписание 2ГИС.
- **Поиск**: кружок, который «расплывается» в многострочную строку ввода над клавиатурой; после отправки строка очищается.
- **Для вас**: открывается после 30 поисков или после выбора от 10 интересов на бесконечном полотне пузырьков; дальше подборку меняют поиски и свайпы.
- **Z Fold / планшеты**: на широком экране шторка становится боковой панелью, строка поиска ограничена по ширине.
- **Квота 2ГИС**: маршруты кэшируются на 10 минут, агент делает не больше 3 проверок маршрута на запрос.

## Быстрый старт без ключей (демо-режим)

Без ключа 2ГИС сервер работает на **демо-данных**: синтетические места вокруг Mega Silk Way, Хан Шатыра, Байтерека, Expo, аэропорта и старого города. Jev заменён классификатором по ключевым словам, Claude — шаблонными текстами. В интерфейсе такие ответы помечены «Демо-данные», а не «Данные 2ГИС». Погода — живая (Open-Meteo без ключа).

Каждый сервис подключается своим ключом. С одним ключом 2ГИС места, время в пути и маршруты настоящие, а фильтры и пояснения остаются запасными — классификатор и шаблоны — пока нет ключей Jev и Claude.

Команды даны для macOS и Linux. В Windows вместо `.venv/bin/python` пишите `.venv\Scripts\python`, вместо `./gradlew` — `gradlew.bat`.

Сервер:

```bash
cd server
uv venv --python 3.12 .venv
uv pip install --python .venv -r requirements-dev.txt
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8080 --no-access-log
```

Приложение (эмулятор ходит на компьютер по адресу `10.0.2.2:8080` — он прописан по умолчанию):

```bash
cd android
./gradlew :app:installDebug
```

Карта рисует растровые тайлы 2ГИС на canvas: ключ и WebGL не нужны. От MapGL JS отказались: в WebView он не рисовал карту.

Все сервисы подключаются самостоятельно, без заявок. Ключи — в `server/.env` (образец — `server/.env.example`), в Cloud Run — из Secret Manager.

## Сервер

```bash
cd server
.venv/bin/python -m pytest -q                                 # 70 тестов
```

| Метод | Путь | Назначение |
| --- | --- | --- |
| POST | `/v1/search` | ИИ-поиск, поток SSE: `filters` → `candidates` → `answer` → `done` (или `error`) |
| GET | `/v1/suggest` | подсказки при вводе |
| GET | `/v1/places/{id}` | карточка места |
| POST | `/v1/route` | маршрут с манёврами (все виды транспорта) |

| POST | `/v1/profile/update` | операции над портретом |
| GET | `/v1/weather` | осадки на час, прогноз на 3 ч, закат |
| POST | `/v1/notify/candidates` | места для уведомления по триггеру |
| GET | `/v1/status`, `/healthz` | что настроено (без значений ключей), расход лимитов 2ГИС |

Заголовок `X-Install-Id` (случайный UUID установки) обязателен; лимит — 60 поисков в сутки на установку. Ошибки — `{"code": "...", "message": "..."}`.

Полезные переменные: `DEMO_MODE=auto|1|0`, `WEATHER_OVERRIDE='{"precip_starts_in_min": 30}'` (подставной прогноз для сценария 12), `PLANNER_FALLBACK=1` (серверный fallback Sonnet 5.5 при отказе модели), `DGIS_PLACE_FIELDS` (поля Places API без правки кода).

### Деплой в Firebase (основной)

Сервер работает как Cloud Functions for Firebase 2-го поколения в проекте `mthread-maps`, регион `europe-west1`:
`https://europe-west1-mthread-maps.cloudfunctions.net/api`. Внутри это Cloud Run, поэтому потоковые ответы поиска (SSE) доходят по мере готовности.

- **Точка входа** — `server/main.py`: то же FastAPI-приложение за WSGI-переходником (`a2wsgi`). Приложение импортируется при первом запросе, потому что Firebase CLI при деплое ждёт загрузки файла не дольше 10 с.
- **Ключи** — секреты Secret Manager: `DGIS_API_KEY`, `OPENROUTER_API_KEY`, `ANTHROPIC_API_KEY`.
- **Локальные ключи** — в `server/.env.local`. Файл `server/.env` не создавайте: Firebase CLI выгрузил бы его открытыми переменными функции.

```bash
cd server && uv venv --python 3.12 venv && uv pip install --python venv -r requirements.txt   # venv нужен Firebase CLI
firebase functions:secrets:set DGIS_API_KEY        # и так же OPENROUTER_API_KEY, ANTHROPIC_API_KEY
firebase deploy --only functions
```

Старые образы контейнеров удаляются через сутки (`firebase functions:artifacts:setpolicy`). Приложение собирается на этот адрес через `api.baseUrl` в `android/local.properties`. Release-сборка (`./gradlew :app:assembleRelease`) не показывает отладочное меню и симуляцию и не читает подставные координаты, время и адрес сервера.

### Деплой в Cloud Run (запасной путь, нужен gcloud)

```bash
cd server
gcloud services enable run.googleapis.com secretmanager.googleapis.com cloudbuild.googleapis.com
printf '%s' "$DGIS_API_KEY" | gcloud secrets create dgis-key --data-file=-
printf '%s' "$JEV_API_KEY" | gcloud secrets create jev-key --data-file=-
printf '%s' "$ANTHROPIC_API_KEY" | gcloud secrets create anthropic-key --data-file=-
printf '%s' "$OPENWEATHER_API_KEY" | gcloud secrets create openweather-key --data-file=-
gcloud run deploy walk-api --source . --region europe-west1 --allow-unauthenticated \
  --min-instances 1 --set-env-vars DEMO_MODE=0 \
  --set-secrets DGIS_API_KEY=dgis-key:latest,JEV_API_KEY=jev-key:latest,ANTHROPIC_API_KEY=anthropic-key:latest,OPENWEATHER_API_KEY=openweather-key:latest
```

`--min-instances 1` — на время демо, чтобы не было холодного старта. Сервисному аккаунту Cloud Run нужна роль `roles/secretmanager.secretAccessor`. В образе uvicorn запускается с `--no-access-log`: журнал доступа пишет строку запроса, а в ней координаты.

## Android

`android/local.properties` (не в git):

```properties
sdk.dir=...
api.baseUrl=https://walk-api-xxxxx.a.run.app   # по умолчанию http://10.0.2.2:8080
```

```bash
cd android
./gradlew :app:testDebugUnitTest   # навигатор, детектор прогулки, триггеры, правила портрета
./gradlew :app:assembleDebug
```

Три вкладки: «Карта», «Для вас», «Профиль». Онбординг из трёх шагов: что умеет приложение, разрешения с объяснением каждого, транспорт по умолчанию. Если «Разрешить всегда» не выдано, прогулка автоматически не определяется — так требует Android 12+.

**Интерфейс** (`ui/fx`): пузыри, слои глубины, физика, тактильный отклик.

- **Пузыри** (`Bubble.kt`): скругления 16–44 dp и «пилюли», плоские яркие заливки без градиентов (синий `#1F6BFF`, жёлтый `#FFC400`, зелёный `#00B37E` на светлом `#F2F4F8`), мягкая тень. Маркеры карты и линейка масштаба нарисованы так же.
- **Слои глубины**: высоту тени задаёт `Depth` — пол, низкий, плавающий, шторка, модальный. Карта — дальний слой. Когда шторка поднимается, карта отъезжает назад: параллакс, масштаб, затемнение, на Android 12+ размытие. На вкладках «Для вас» и «Профиль» карта уходит под плотную подложку и не отвечает на касания. Новый экран всплывает из глубины, панель вкладок плавает над всеми слоями.
- **Физика** (`Physics.kt`):
  - Шторка: у неё три якоря. Бросок проецируется по затуханию с трением на ближайший якорь, доводит его пружина с исходной скоростью пальца. За крайними якорями — «резинка».
  - Списки прокручиваются с настраиваемым трением.
  - Колода: карту бросают с инерцией. Она улетает до границы за краем экрана. Если броска не хватило, пружина возвращает её назад. Задние карты подъезжают, пока верхнюю тянут к порогу.
  - Карта после броска катится по инерции с трением; двойной тап приближает, щипок масштабирует вокруг пальцев.
- **Тактильный отклик** (`Haptics.kt`): примитивы `VibrationEffect.Composition` для линейного вибромотора (LRA) — клик, тик, глухой удар, подъём и спад. Где примитивов нет, вместо них играют предустановленные эффекты или короткие импульсы.
  - Нажатие: на пузыре — клик, на чипе и вкладке — лёгкий тик. Сам пузырь при этом продавливается и наклоняется к пальцу.
  - «Фактура» при протаскивании карты колоды: импульс каждые ~26 px, сила зависит от скорости.
  - Щелчок на пороге свайпа и при проходе якоря шторки.
  - Удар при посадке шторки: сила зависит от скорости.
  - Разные паттерны для «Хочу» и «Не то», для пришедшего и пустого ответа.
  - Подсказки навигатора: манёвр, сход с маршрута, прибытие. Их играет сервис навигации, поэтому они работают и при выключенном экране.

  Отклик отключается в Профиль → Ощущения.

**Отладочное меню** (Профиль → Отладка, только debug-сборка): подстановка координат (Mega Silk Way, Expo, аэропорт, Хан Шатыр), сдвиг времени, принудительный старт прогулки, адрес сервера. В шторке маршрута есть переключатель «Симуляция движения»: точка едет по маршруту, а с 30-й по 45-ю секунду уходит на 40 м в сторону — так проверяется сценарий 14.

## Как закрыты требования задачи

- **1–3 рекомендации с причиной, временем на посещение и действием.** Claude выбирает только из кандидатов; факты (время в пути, режим работы, рейтинг) подставляет код.
- **Пометка источника**: «Данные 2ГИС», «Идея модели», в демо-режиме — «Демо-данные».
- **Честность о режиме работы**: три состояния — открыто, закрыто, нет данных. Для «нет данных» код не допускает слово «открыто» в ответе. Признаки без атрибута в 2ГИС (розетки, туалет) помечаются «не подтверждено».
- **Минимум хранимых координат**: на сервер уходит точка, округлённая до 3 знаков (~110 м); Jev координат не получает; портрет и история остаются на телефоне; сервер хранит только кэш ответов внешних API (2ГИС — до 24 ч, погода — 10 мин). Отрезок от точной позиции до начала маршрута навигатор достраивает на устройстве.
- **Автоматизированный сбор данных**: конвейер извлечения из API в момент запроса; образцы ответов для сценариев — через `check_keys.py`.

## Отличия от ТЗ и решения по ходу

- **Слоты `c1…c8` вместо `poi_id` в `enum`.** JSON-схема ответа Claude перечисляет стабильные слоты кандидатов, код сопоставляет их с id 2ГИС. Гарантия «место вне списка не попадёт в ответ» сохраняется. При этом схема не меняется от запроса к запросу, и API не компилирует её заново (новая схема компилируется с задержкой, кэш — 24 ч). Поддержка `enum` в подмножестве JSON Schema подтверждена документацией Claude.
- **TSP API 2ГИС не вызывается.** У Jev максимум две группы промежуточных точек (покупка и вторая категория). Код перебирает их порядки (до 4 групп — 24 варианта) и кандидатов полностью.
- **Радиусы в режиме плана.** Точку с зонтом ищем в радиусе, достижимом до дождя (t_rain − 3 мин); цель — в радиусе ≥ 30 мин, потому что путь идёт через промежуточную точку.
- **«Где не был»** фильтруется на устройстве: история посещений не покидает телефон.
- **Колода** ранжируется на устройстве (θ ~ Beta, новизна N, разнообразие). Сервер считает K, Q, время в пути и пишет тексты одним вызовом Haiku на все кандидаты.
- **Название приложения** — рабочее («Прогулка»); бренд — открытый вопрос ТЗ.

## Сверить в первый день

Разбор ответов защищён от отсутствующих полей, имена полей Places вынесены в `DGIS_PLACE_FIELDS`.

- [ ] Places API: поля режима работы (`schedule`), рейтинга (`reviews.general_rating`, `general_review_count`), атрибутов (`attribute_groups[].attributes[].tag/name`), числа филиалов (`org.branch_count`); формат `work_time` (`now`, `today,HH:MM`) и `opened_after_date`; `locale=ru_KZ`.
- [ ] Distance Matrix: принимает ли `transport=public_transport`, `scooter`, `taxi` (если нет — время помечается «оценено приблизительно»).
- [ ] Routing API 7.0.0: формат `maneuvers` и `outcoming_path.geometry[].selection` (WKT); Public Transport API 2.0 — формат вариантов.
- [ ] Ссылка в приложение 2ГИС: подтверждено `rsType/car`; проверить значения для пешехода и транспорта (в коде — `pedestrian`, `bus`).

- [ ] Праздники Казахстана в `server/app/data/holidays.yaml`: плавающие даты сверить с официальным календарём.
- [ ] Тактильный отклик — на телефоне с линейным вибромотором (Pixel, Galaxy S): в эмуляторе вибромотора нет, поэтому отклик там не проверялся.
