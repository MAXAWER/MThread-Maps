# Монетизация «Прогулки»

Принцип: **ответы ИИ не продаются.** Модель выбирает места только по качеству и запросу. Деньги приносят
переходы к партнёрам (такси, доставка, билеты, бронь), помеченная реклама в ленте «Для вас» и подписка «Плюс».

## Что уже работает в приложении

| Канал | Где в приложении | Как зарабатывает | Что нужно подключить |
|---|---|---|---|
| Такси | Маршрут → «Такси»: цены по тарифам, кнопка «Заказать» | CPA за поездку по партнёрской ссылке | ID партнёра Яндекс Go (`YANDEX_TAXI_REF`), для точных цен — `YANDEX_TAXI_CLID` и `YANDEX_TAXI_APIKEY` |
| Доставка | Карточка ИИ: «Заказать в Glovo / Wolt / Яндекс Еде / Chocofood» | CPA/CPS по партнёрскому параметру | Параметры партнёрок `AFF_<ДОМЕН>` |
| Билеты | Карточка ИИ: «Билеты на Ticketon / Kino.kz» | Комиссия с билета | `AFF_TICKETON_KZ`, `AFF_KINO_KZ` |
| Бронь столиков | Карточка ИИ: «Забронировать столик» (Restoplace) | Плата за бронь | `AFF_RESTOPLACE_KZ` |
| Реклама мест | Лента «Для вас»: пометка «Реклама», предложение, промокод | Оплата за показ / переход / промокод | Файл `server/data/promotions.json` или `PROMOTIONS_JSON` |
| Предложения партнёров в ответах ИИ | «Партнёр · Реклама» под карточкой, если ИИ сам выбрал это место | Комиссия по промокоду | Тот же список акций |
| Подписка «Плюс» | Профиль → «Прогулка Плюс» | Ежемесячная подписка | Google Play Billing (ниже) |
| Учёт | Все переходы и клики | Основа для счетов партнёрам | `ADMIN_TOKEN` для `/v1/admin/stats` |

### Такси: как устроен переход

Сервер (`/v1/taxi/estimate`) строит маршрут на авто и отдаёт по каждому партнёру тарифы и ссылку.

- **Яндекс Go:** официальная ссылка на заказ
  `https://3.redirect.appmetrica.yandex.com/route?start-lat…&start-lon…&end-lat…&end-lon…&tariffClass=econom&ref=<ID>&appmetrica_tracking_id=1178268795219780156`.
  Она открывает приложение сразу с точками «откуда» и «куда», а без приложения ведёт в магазин.
  Источник: <https://yandex.com/support/taxi-distr/en/api/deeplinks>.
- **inDrive:** публичного формата ссылки с точками нет. Приложение открывается, адрес назначения копируется в буфер.
- **Цены:** с ключами Яндекса — через API расчёта стоимости `taxi_info` (<https://yandex.com/support/taxi-distr/en/api/trip-info>).
  Без ключей — оценка по расстоянию и времени с пометкой «оценка».

## Подключение партнёрских программ

1. **Яндекс Go — дистрибуция такси:** регистрация на <https://yandex.com/support/taxi-distr/>.
   - Получите ID источника (`ref`) и CLID с типом «Ссылка на заказ поездки».
   - Для цен нужен ключ API расчёта стоимости.
   - Переменные окружения функции: `YANDEX_TAXI_REF`, `YANDEX_TAXI_CLID`, `YANDEX_TAXI_APIKEY` (ключи — в Secret Manager).
2. **Доставка и билеты:** договор с Glovo, Wolt, Яндекс Едой, Chocofood, Ticketon, Kino.kz, Restoplace.
   - Их параметр отслеживания задаётся переменной `AFF_<ДОМЕН>`, где точки и дефисы заменены на `_`.
   - Пример: `AFF_GLOVOAPP_COM="utm_source=progulka&utm_medium=app&aff_id=123"`.
   - Кнопка появляется только там, где ИИ реально нашёл страницу этого места у партнёра.
3. **Новые партнёры:** добавить домен в `LINK_KINDS` в `server/app/partners.py` (вид, название, текст кнопки).

## Реклама мест

Список акций — `server/data/promotions.json` или переменная `PROMOTIONS_JSON`; формат — в `server/data/promotions.example.json`.

- `brand` или `poi_id` — какое место;
- `offer`, `promo_code` — что получит пользователь;
- `boost` — насколько поднять место в ленте (0,1–0,3);
- `until` — дата окончания.

Правила:

- Реклама показывается только в ленте «Для вас» и всегда помечена «Реклама» (Закон РК «О рекламе»).
- В ответах ИИ реклама не поднимает места. Если ИИ сам выбрал место-партнёр, рядом видно его предложение с пометкой «Партнёр».

## Подписка «Прогулка Плюс»

Сейчас кнопка «Хочу Плюс» отправляет переход `kind=plus` — это замер спроса.

Чтобы включить оплату:

1. Опубликовать приложение в Google Play (закрытое тестирование подойдёт) и создать подписку `progulka_plus_monthly` в Play Console.
2. Подключить `com.android.billingclient:billing-ktx`:
   - `BillingClient` с `enablePendingPurchases`;
   - `queryProductDetailsAsync` → `launchBillingFlow`;
   - подтверждение покупки `acknowledgePurchase`.
3. Проверять покупку на сервере через Google Play Developer API (`purchases.subscriptionsv2.get`) и хранить права по `X-Install-Id`.
4. Права «Плюса»:
   - офлайн-карта всего города (предзагрузка тайлов 15–16 по Астане);
   - без рекламы в ленте;
   - безлимитные маршруты ИИ по многим точкам.

## Учёт и сверка с партнёрами

- Приложение шлёт `/v1/clickout` при каждом переходе к партнёру и использовании промокода.
- Сервер пишет строку `clickout {...}` в Cloud Logging и считает переходы в памяти: `GET /v1/admin/stats` с заголовком `Authorization: Bearer <ADMIN_TOKEN>`.
- Для отчётов партнёрам: приёмник журнала в BigQuery с фильтром `textPayload:"clickout"`.

## Что ещё можно продавать дальше

- **Кабинет бизнеса:** место видит, как часто его рекомендует ИИ и почему, и может купить показ в ленте.
- **Обезличенная аналитика спроса для бизнеса и города:** что ищут, где не хватает мест. Только агрегаты, без персональных данных.
- **Готовые маршруты-экскурсии** с музеями и кафе-партнёрами — продаются как услуга или за счёт партнёров.
- **Корпоративные выходы и тимбилдинги** — подбор и бронь мест на группу.
